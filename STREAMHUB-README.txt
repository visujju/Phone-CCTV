StreamHub — TV Browser

Run locally:
  npm install
  npm start

Then open http://localhost:3000

Remote controls: arrows navigate, Enter/OK opens, Escape/Back returns, T themes,
S or / opens URL/search, H or ? opens help, C cycles categories, R launches a
random site, and 1–8 launch the first eight services.

This package preserves the original CCTV camera and viewer routes at /camera
and /viewer.
